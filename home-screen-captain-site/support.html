Support

Simple troubleshooting and help for Home Screen Captain.

Last updated: September 14, 2026
Need help? Home Screen Captain does not require an account, so there is no password or account-recovery process. Most settings can be changed directly on the device.

Set Home Screen Captain as the launcher

Open Android Settings, find the Default apps or Home app setting, and select Home Screen Captain. Menu names can differ by device manufacturer and Android version.

Switch back to another launcher

Open Android Settings and choose another Home app or default launcher. You can switch launchers without deleting your other apps.

Optional large-key keyboard

The keyboard is optional. Enable or disable it from Android's keyboard or input-method settings. Home Screen Captain is designed not to collect or store what you type.

Accessibility Service

The shopping-assistance Accessibility Service is optional. It can be turned off from Android Accessibility settings at any time. Disabling it does not require an account.

Search and shortcuts

Search and shortcut behavior can depend on the app version and device configuration. If a feature is not responding, restart the app and check the internet connection.

Uninstall the app

First select another launcher if necessary, then uninstall Home Screen Captain using Android Settings or Google Play.

Before contacting support

  1. Restart the device.
  2. Make sure Home Screen Captain is updated to the latest version available on Google Play.
  3. Check that the required optional feature is enabled only if you want to use it.
  4. If a third-party feature such as search or weather is not responding, check the internet connection and try again.

Contact support

Use the developer support email shown on the official Home Screen Captain Google Play listing. When contacting support, include the device model, Android version, app version, and a short description of the problem. Do not send passwords, payment-card details, banking information, or other sensitive information.

Privacy questions

For questions about privacy, please read the Privacy Policy and use the same developer contact information shown on Google Play.
